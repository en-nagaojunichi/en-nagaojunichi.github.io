## このリポジトリについて

このリポジトリには、個人ポートフォリオサイトのHTML、CSS、画像を収録しています。

### 構成

- `index.html` — プロフィール、開発事例、技術領域、相談先
- `projects/mamead.html` — Laravel / MameAd の設計・実装事例
- `projects/flutter.html` — Flutter / 公開アプリ 3 本の実装事例
- `styles.css` — 共通スタイル
- `assets/` — 自身が開発したサービス・アプリの画面と図
